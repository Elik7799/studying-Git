С помошью Git программисты и разработчики орнентируются в коде и отслеживают изменення. Git помогает вернуть файлы в исходное состоянне и видеть изменения, внесённые в определённый пернод. Разработчик выполняет разные команды (например, commit, push), а все изменения сиихронизируются с центральным репозиторием. Git - это система контроля версий, a GitHub - онлайн-сервис, по сути социальная сеть. Одна из основных целей GitHub - быть единым местом для проектов с исходным кодом. Предполагается, что пользователь делится чем-то полезным, а другие люди смогут участвовать в разработке.
